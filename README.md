# AMPS Tech — Apresentação Institucional do Time

Este repositório contém a apresentação institucional da estrutura operacional de IA da AMPS Tech.

## Arquivos principais

- `docs/apresentacao-institucional-amps-tech.html` — apresentação HTML autocontida, sem imagens de agentes, com logo AMPS Tech aplicado.
- `docs/apresentacao-institucional-amps-tech.pdf` — versão exportada para PDF a partir do navegador.
- `docs/assets/logo-amps-tech.jpg` — logo institucional usado na apresentação.

## Direção visual

A apresentação usa uma linguagem executiva e institucional, baseada na paleta do site AMPS Tech:

- Dark tech: `#0D1121`
- Turquesa neon: `#00E5D3`
- Turquesa profundo: `#00B4A6`
- Branco: `#FFFFFF`
- Cinza claro: `#DCE0F7`

## Estrutura

A nova versão não usa caricaturas nem imagens dos agentes. O foco é apresentar a AMPS Tech como uma estrutura operacional de IA organizada por squads:

- Orquestração e governança
- Marketing & Growth
- Produto, UX e Qualidade
- Tecnologia, Dados, IA, Segurança e DevOps
- Fronteira Marketing → Vendas

## Impressão

O HTML foi desenhado em formato A4 paisagem e pode ser aberto no navegador para impressão ou exportação em PDF.
